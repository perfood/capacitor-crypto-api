capacitor-crypto-api example

This example demonstrates the use of the capacitor-crypto-api plugin. The plugin provides a simple API to create and manage key-pairs, sign and verify data, encrypt and decrypt data.

ECDSA - sign and verify data

This example demonstrates a simple 2-factor-authentication mechanism. The client creates a key-pair and registers the public-key with the server. The server creates a challenge and sends it to the client. The client signs the challenge with the private-key and sends the signed data back to the server. The server can then verify the signature of the data with the public-key and be sure that the data was signed by the private-key.

ECDH - encrypt and decrypt data

This example demonstrates a simple end-to-end encryption mechanism. The client creates a key-pair and encrypts the data with the foreign public-key. The foreign party can then decrypt the data with its private-key and the clints public-key. The client can also decrypt the data with its private-key that was encrypted from the remote party.
